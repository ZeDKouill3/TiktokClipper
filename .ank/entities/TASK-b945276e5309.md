## But (décision utilisateur 12/10)
Test A/B des titres d'écran : chaque compte TikTok actif a UN style de titre (`citation`, `promesse`, `promesse_emoji`, SPEC-810f), avec rotation chaque semaine pour que chaque compte essaie chaque style (les comptes n'ont pas la même audience : ClippTVFR fait 2 à 4x les vues médianes de TwitchClipperTV). Le titre est incrusté dans la vidéo : un clip ne peut partir que sur un compte dont le style du jour = le style du clip.

Rotation (début 2026-10-14, semaine = 7 jours depuis le début, heure de Paris) :
| Semaine | ClipperFou 1ad53325b65d | TwitchClipperTV 5fb241d5fb53 | ClippTVFR 17c3783183e1 |
| 1 | citation | promesse | promesse_emoji |
| 2 | promesse | promesse_emoji | citation |
| 3 | promesse_emoji | citation | promesse |
Formule : style(compte i, semaine w) = styles[(i + w) % n], ordre des comptes et des styles en config.

## À faire
1. **Réglages** (`[repartition]`, CONFIG_DEFAULTS de repartition.py) : `title_ab_enabled` (false par défaut), `title_ab_start` (date), `title_ab_accounts` (liste ordonnée d'ids), `title_ab_styles` (liste ordonnée). Validation stricte (style inconnu, compte en double, date invalide = erreur nommée, ADR-ad2e). Fonction pure `title_style_for(account, day, settings)`.
2. **Style d'un clip** : le rendu écrit dans le sidecar `screen_title_style` (lu dans la section `[captions]` effective de la vidéo au moment du rendu) ET `title_shown` vrai/faux réel. En split, `title_shown` doit refléter le titre réellement dessiné (aujourd'hui il vaut `letterbox and title_enabled`, faux en split même quand le titre split est dessiné : à corriger, test à l'appui). Un clip sans titre dessiné ou sans `screen_title_style` n'est éligible à AUCUN compte du test (jamais deviné), et le plan le dit (refus explicite, comme les autres refus de SPEC-6d1f).
3. **Plan (repartition)** : si `title_ab_enabled`, pour un compte de `title_ab_accounts`, seuls les clips dont `screen_title_style` = style du compte ce jour-là sont candidats ; le reste des règles SPEC-6d1f inchangé. Comptes hors liste : inchangés. Chaque ligne du plan expose le style (pour l'écran Répartition : afficher le style du compte et du clip, libellés français ; fichier d'écran à trouver dans clipper/web/static/screens/).
4. **Vidéos nouvelles** : quand le test est actif, le pipeline choisit le style de titre d'une vidéo au moment de l'étape captions = le style qui a le MOINS de clips disponibles (non publiés, prêts) parmi `title_ab_styles` (équilibre l'offre), l'écrit dans pipeline.json (`title_style`) et l'applique à la config `[captions]` de cette vidéo (sans toucher au preset). Une reprise/relance garde le style déjà écrit. Aucune étape n'importe une autre étape (ADR-b16b) : le décompte passe par pipeline ou une fonction pure.
5. **tools/retitle_stock.py** : option `--style` (citation|promesse|promesse_emoji, défaut promesse) pour retitrer une vidéo du stock dans un style donné (aujourd'hui il refuse tout autre style que promesse).
6. **Spec** : nouvelle spec (référence SPEC-6d1f et SPEC-810f) décrivant ces règles ; proposée seulement.
7. Tests unitaires (repartition, render, pipeline, retitle) : rotation exacte du tableau ci-dessus ; clip d'un autre style refusé avec raison ; clip sans style refusé ; title_shown en split ; choix du style le moins fourni ; relance garde le style ; --style.

## Hors périmètre (l'orchestrateur le fera après fusion)
Re-rendre le stock, activer le test dans config.toml. Ne lancer aucun rendu réel, ne pas toucher config.toml ni presets/.
