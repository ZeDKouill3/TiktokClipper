Demande propriétaire 23/10 : « il faut une IP pour chaque compte ». Chaque compte de publication (TikTok, YouTube) peut avoir son propre proxy de sortie ; le navigateur piloté (`clipper.browser._open_context`, utilisé par publication, connexion, relevé de stats, Bizarrium `ai-video/publish_tiktok.py`) sort alors par ce proxy et jamais par l'IP de la box.

Doc Playwright (launch_persistent_context, option `proxy`) : `server` http:// ou socks5://, `username`/`password` « if HTTP proxy requires authentication » (https://playwright.dev/python/docs/api/class-browsertype). Donc proxy authentifié = HTTP seulement ; un socks5 avec identifiants est refusé à l'enregistrement.

Cible achat : proxys ISP résidentiels statiques (une IP fixe par compte, pays = expected_country du compte).
