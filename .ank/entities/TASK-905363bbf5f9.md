Contexte : config.toml fixe [captions] screen_title_max_chars = 35 (étude du 13/10 : titres > 35 caractères = médiane 80 vues contre 251). captions.py refuse déjà ces titres pour les nouveaux clips, mais le stock ancien en contient : chaque jour l'orchestrateur remplaçait à la main ces lignes du plan avant validation.

À faire dans clipper/repartition.py : lire le plafond dans la table [captions] de la config (ne pas importer clipper.captions : une étape n'importe pas une autre, ADR-b16b ; lire config["captions"]["screen_title_max_chars"] avec la valeur par défaut 0 si absente), écarter du vivier les clips dont len(screen_title) > plafond, et tracer chaque refus (vidéo, clip, longueur, plafond) dans le plan, à la manière de ab_refused. Le choix manuel reste possible (SPEC-6d1f : modifiable par l'utilisateur) mais porte un warning. Aucun repli silencieux (ADR-ad2e).
