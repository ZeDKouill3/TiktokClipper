### Objet
Ce que l'interface montre et permet, écran par écran, et les règles transverses. Le style
visuel est normé par ADR-a308c4cafb5b et `research/drafts/ui-v3/DIRECTION.md` (jetons, typo,
mouvement). Tout texte en français, heure de Paris, aucun nom réel dans le code, les
fixtures ni les captures du dépôt (`ma_chaine`, `compte_alpha`).

### Règles transverses
- **T1** (inchangée) L'API ne contient aucune logique vidéo/audio/LLM ; la page est statique,
  sans étape de build ; bibliothèque vendored selon ADR-a308c4cafb5b.
- **T2** (inchangée, précisée) Aucune valeur de secours silencieuse : toute erreur d'API porte
  `{"detail"}` en français et s'affiche **en place** (`role="alert"` sous le champ, ligne rouge
  dans la liste, `alert[data-variant=destructive]` dans la zone) **et** en toast ; jamais « — »
  sans sa cause ; une donnée partielle le dit.
- **T3** (inchangée, précisée) Temps réel par `/api/events` ; chaque événement recharge
  l'objet concerné et met l'écran à jour **par rapprochement du DOM** (jamais de
  réécriture complète) : focus, défilement, lecture vidéo, hauteurs conservés. Repli polling
  5 s + bandeau « connexion perdue ». Une vidéo en cours montre étape, fraction, ETA.
- **T4** (inchangée) Confirmation ou « Annuler » 5 s dans le toast pour toute action
  destructive ou coûteuse ; les actions groupées (« Relancer les 4 ») confirment une fois en
  nommant le nombre.
- **T5** (inchangée) Toasts pour `done`, `failed`, `awaiting_review`, `queued` ; notification
  navigateur si autorisée.
- **T6** (précisée) Mobile ≥ 360 px : barre d'onglets basse (Accueil, Vidéos, Revue, Clips,
  Publication), tables repliées en lignes étiquetées, calendrier en agenda, tiroirs plein
  écran, cibles ≥ 44 px, aucun défilement horizontal de page sur aucun écran.
- **T7** (inchangée) Jeton demandé une fois hors bouclage, gardé en cookie ; 401 sinon.
- **T8** (précisée) Squelette de la forme du contenu final ; état vide qui dit quoi faire et
  pourquoi c'est vide ; jamais de page blanche.
- **T9** (nouvelle) **La décision d'abord** : chaque écran commence par ce qui attend
  l'opérateur ; les statistiques froides vont dans Statistiques.
- **T10** (nouvelle) **Contexte conservé** : fiche clip, détail d'une étape, nouvelle
  publication, édition d'un compte s'ouvrent en tiroir ou `<dialog>` par-dessus la liste ;
  l'URL (`#/…`) suit toujours ; Échap, clic dehors et bouton ferment.
- **T11** (nouvelle) **Clavier** : `Ctrl/⌘ K` palette (écrans, vidéos par titre ou id,
  actions) ; `g` puis `d v c p s` ; `/` recherche de l'écran ; `n` ajouter une vidéo ; `?`
  aide ; `j k Entrée` dans les listes ; `a r` dans la fiche clip et la revue (qui garde aussi
  `J K espace`). Aucune animation sur une action clavier.
- **T12** (nouvelle) **Thème clair par défaut**, sombre mémorisé par navigateur ; un seul
  thème par page.
- **T13** (nouvelle) **Pays de l'IP** : pastille compacte (icône + code pays) ; rouge
  seulement hors pays attendu ; l'alerte détaillée n'apparaît qu'au moment d'une publication
  (dialogue « Nouvelle publication », bouton Publier) et dans Comptes.

### Écrans
- **E1 Tableau de bord** : bandeau KPI (en cours, en file, à débloquer, clips à valider,
  coût LLM jour + 7 j, worker + GPU) ; section **À faire** : échecs **regroupés par cause**
  avec action groupée et action par ligne (« Relancer depuis <étape> », retirer), vidéos
  `queued` avec `retry_at`, VOD à confirmer, clips à valider (compte), posts 0 vue ; section
  **En cours** (étape, fraction, ETA, annuler) ; file d'attente (passer en tête, retirer) ;
  **Dernières vidéos terminées** (6, table) ; rail : prochaines publications, coût par usage
  (6 premiers + reste), espace disque. Le détail coût par vidéo et durée par étape ne sont
  plus sur cet écran (E8).
- **E2 Vidéos** : **table** triée par mise à jour (vignette + titre + id + plateforme, style,
  statut, étape avec barre, clips, mise à jour), filtres (texte serveur, statut segmenté avec
  compteurs, style), menu « … » (purger les terminées, export), ajout par le dialogue global
  (plus de formulaire permanent). **Fiche** (`#/videos/<id>`) : en-tête (vignette, titre,
  statut, id copiable, style, mode, grille libellée sans chemin, clips courts, lien source),
  actions (Voir les N clips, Relancer depuis… menu des étapes, … purger) ; frise des 13
  étapes qui se replie sans orphelin ; détail de l'étape choisie (durée, début, fin, raison,
  relancer) ; bande des clips ; journal en **table** (heure, niveau coloré, étape, message
  replié) avec filtre, « suivre en direct », copier.
- **E3 Revue des moments** : inchangée sur le fond (lecteur calé, score, accroche,
  justification, bornes, accepter / refuser / ajuster, `A R J K espace`, rendu bloqué tant
  qu'une décision manque) ; état vide qui explique le mode `review` et propose le sélecteur
  de vidéo ; mise à jour par rapprochement (plus de DOM gardé à la main).
- **E4 Clips** : galerie 9:16 par statut (onglets **sans les statuts à zéro**, compteurs),
  filtre vidéo par **titre** (pas l'id seul), style ; carte = image, durée, badge QA, titre
  d'écran, score, id ; sélection groupée (approuver pour un compte, supprimer) ; **fiche
  clip en tiroir** (`#/clips/<video>/<clip>` et `#/videos/<id>/clip/<clip>`) : lecteur,
  scores, accroche, bornes, format, raison, jury (ou « non évaluée » avec la cause), QA avec
  avertissements, légende / hashtags / titre d'écran éditables (titre = re-rendu confirmé),
  publication, **actions** Approuver (compte), Refuser (série entière confirmée), Re-rendre,
  navigation `j k`, `a r`.
- **E5 Styles** : inchangé sur le fond (liste, formulaire par section avec héritage, éditeur
  d'agencement, aperçu sous-titres, logo) ; libellés français devant chaque clé technique
  (`watch_interval_s` → « Intervalle de surveillance (s) ») ; sections dépliables avec
  état visible ; « Supprimer » dans le menu « … », jamais à côté d'« Enregistrer ».
- **E6 Publication** : **calendrier d'abord** (jour / semaine / mois, compte choisi par
  défaut = dernier utilisé, jour courant marqué, posts = heure, titre, compte, état par
  couleur, « + N autres », bouton « + » sur un jour futur), glisser-déposer entre jours /
  créneaux ; rail **À faire** : plan de demain (état, Calculer, Valider avec raison si
  grisé), en attente, en échec (capture, réessayer), supprimés de la plateforme ; dialogues
  **Nouvelle publication** (clip, compte prêt, maintenant / date, description, options
  repliées, alerte IP) et **Programmer une série** ; bandeau d'aide remplacé par une infobulle.
  Sur mobile : agenda.
- **E7 Statistiques** : KPI TikTok par compte / période, courbe, liste des vidéos, fiche
  post, apprentissage (boucle, poids, rétention, coach) ; **aucun « — »** : une tuile absente
  dit « non fourni par TikTok Studio » ; sections d'apprentissage en cartes.
- **E8 Réglages** : formulaire par section avec sommaire **collant**, libellés français,
  bouton Enregistrer **collant** en bas, accès en lecture seule ; coût LLM par vidéo et durée
  par étape déplacés ici ou dans E7 (au choix de la tâche, à dire dans son critère).
- **E9 Veille** (nouvelle dans la spec, reprend SPEC-bdd9 / SPEC-df51) : sommaire en tête
  (relevé, propositions, sorties, jeux qui montent, meilleurs clips), relevé des sources en
  table compacte (source, état, compteurs, erreur), propositions = décisions d'abord
  (Clipper / Ignorer), jaquettes en bande défilante, pas de page de 24 000 px.
- **E10 Comptes** (reprend SPEC-6fa4 / SPEC-f348) : table (compte, service, connexion,
  prêt à publier, créneaux, posts du jour) ; actions fréquentes en ligne (copier identifiant /
  mot de passe, se connecter), le reste dans « … » ; édition en tiroir ; générateur de mot de
  passe en dialogue.
- **E11 Journal** : table à colonnes fixes, message replié, niveau coloré, filtre texte et
  niveau, rafraîchir, **aucun défilement horizontal**.
- **E12 Fiche clip** : voir E4 (tiroir), plus la page plein écran `#/clip/<v>/<c>` qui
  affiche le même contenu pour un lien partagé.
